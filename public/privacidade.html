Transparência técnica

Privacidade e armazenamento local

O Observatório não exige conta para consultar os dados. O código da interface não implementa cadastro de nome, e-mail, telefone ou localização precisa para usar os painéis.

O que fica no seu navegador

Algumas preferências e recursos usam armazenamento local do navegador para funcionar entre visitas. Isso pode incluir tema, contraste, modo de leitura, seções recentes, indicadores salvos, progresso do aprendizado guiado e pontuações do quiz.

O armazenamento de sessão também pode registrar a dispensa do convite de instalação e identificadores técnicos de erro usados para recuperação da interface. Esses dados permanecem no contexto do navegador, salvo quando uma integração externa é explicitamente acionada.

Telemetria técnica opcional

O código oferece integração opcional com Sentry para diagnóstico de erros quando uma implantação configura um DSN. Essa integração é inicializada com sendDefaultPii: false. Se não houver DSN configurado, o módulo de telemetria não é ativado.

Relatos de erro técnico não devem ser usados para inserir dados pessoais. Links para portais governamentais, GitHub e outros serviços externos seguem as políticas desses serviços.

Como limpar preferências locais

Você pode apagar os dados locais pelas configurações de armazenamento/site do seu navegador. Alguns recursos também oferecem ações próprias, como limpar leituras salvas ou reiniciar o progresso guiado.

Revisado em 30/09/2026. Esta descrição acompanha o comportamento implementado no código público do projeto.
