# Histórico de snapshots TSE 2026

Cada sincronização válida pode preservar o snapshot municipal filtrado e seu manifesto neste diretório. O histórico é intencionalmente pequeno: o Observatório guarda o recorte monitorado, não o arquivo bruto nacional do TSE.

Cada snapshot deve registrar snapshotId, hash SHA-256 do arquivo de origem, data/hora de download, quantidade de linhas, commit e execução do workflow quando disponíveis.
